# Machine Learning 2026 · Week 07: Regularization

Interactive lab for the Week 07 lecture notes, Chapter 9 (Regularization and Model Selection).

- Site: https://sebastian-stapf.github.io/ml2026-week07-regularization/
- Companion lab (deep learning): https://sebastian-stapf.github.io/ml2026-week06-deep-learning/

The page is built from `src/`. Edit the sources, then rebuild:

```sh
python3 build.py
```

`build.py` inlines `src/lab.css` and `src/lab.js` into `index.html`, so the site is a single self-contained HTML file. GitHub Pages serves the repository root.
